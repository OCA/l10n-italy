1. Sul conto bancario dell'azienda (o nella Configurazione RiBa sbf)
   impostare il *Bank Receipts Facility* (fido concesso dalla banca).
2. Contabilità > RiBa > Bank Receipts Facility: scegliere la data di calcolo
   (default oggi + 30 giorni) ed eventualmente le banche, poi *Compute*.
3. *RiBa Detail* apre l'elenco raggruppato per banca e scadenza
   (anche in pivot); *Export Excel* scarica riepilogo e dettaglio.
4. *Overdue not Closed* segnala le RiBa ancora "accreditate" oltre la
   scadenza: manca la chiusura o l'insoluto.
