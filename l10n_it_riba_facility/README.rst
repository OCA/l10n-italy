Calcola il castelletto RiBa salvo buon fine per banca a una data:
impegnato ad oggi, impegnato e disponibile alla data, presentate da
accreditare, saldo del conto RiBa come controllo, dettaglio delle RiBa
per scadenza ed export Excel.

Regola: una RiBa impegna il castelletto dalla data di accredito della
distinta fino alla data di scadenza compresa; è libera dal giorno
successivo, oppure dalla data dell'insoluto se precedente.

Usage
=====

1. Sul conto bancario dell'azienda (o nella Configurazione RiBa sbf)
   impostare il *Bank Receipts Facility* (fido concesso dalla banca).
2. Contabilità > RiBa > Bank Receipts Facility: scegliere la data di
   calcolo (default oggi + 30 giorni) ed eventualmente le banche, poi
   *Compute*.
3. *RiBa Detail* apre l'elenco raggruppato per banca e scadenza (anche
   in pivot); *Export Excel* scarica riepilogo e dettaglio.
4. *Overdue not Closed* segnala le RiBa ancora "accreditate" oltre la
   scadenza: manca la chiusura o l'insoluto.
