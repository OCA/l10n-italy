**English**

Open a posted vendor bill that uses a reverse-charge (self-invoice) tax, or a
regular customer invoice. Click *Generate XML* to create and preview the
FatturaPA XML attachment. Review the attachment in the chatter, then click
*Send to SDI* to submit the same XML to the Exchange System.

To generate the XML for several moves at once, select them in the list view
and click *Generate XML* in the header, or use the *Action* menu. A summary
notification reports the generated, failed and skipped moves.

**Italiano**

Aprire una fattura fornitore registrata che utilizza un'iva in reverse charge
(autofattura) oppure una fattura cliente ordinaria. Cliccare *Genera XML* per
creare e visualizzare l'allegato XML FatturaPA. Rivedere l'allegato nella
cronologia, quindi cliccare *Invia a SDI* per inviare lo stesso XML al Sistema
di Interscambio.

Per generare l'XML di più movimenti in una volta, selezionarli nella vista
elenco e cliccare *Genera XML* nell'intestazione, oppure usare il menu
*Azione*. Una notifica di riepilogo riporta i movimenti generati, non riusciti
e saltati.
