Questo modulo consente di stampare i registri IVA in un database
aggiornato dalla versione 16 alla versione 18, leggendo i dati dalle
registrazioni effettuate nella versione 16 con moduli che non esistono
più, come l10n_it_reverse_charge.

This module allows printing VAT registers in a database updated from
version 16 to version 18, reading data from registrations made in
version 16 with modules that no longer exist, such as
l10n_it_reverse_charge.
