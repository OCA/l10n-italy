Italiano
~~~~~~~~

Andare in Contabilità > Rendiconti > Imposte > Registri IVA.
Selezionare il registro IVA desiderato, il periodo di stampa e gli
altri parametri come di consueto.
Premere il pulsante "Print V16 compat" per generare il PDF oppure
"Print V16 compat XLSX" per generare il file Excel.

Questi pulsanti utilizzano la logica di calcolo della versione 16 per:

- Calcolo degli importi delle imposte per riga di fattura (senza i
  filtri introdotti nella versione 18)
- Visualizzazione del fornitore originale nelle autofatture di reverse
  charge create dalla versione 16
- Calcolo dei totali delle imposte con la logica della versione 16

English
~~~~~~~

Go to Accounting > Reports > Taxes > VAT Registries.
Select the desired VAT registry, the print period and other parameters
as usual.
Press the "Print V16 compat" button to generate the PDF or
"Print V16 compat XLSX" to generate the Excel file.

These buttons use the version 16 calculation logic for:

- Tax amount computation per invoice line (without the filters
  introduced in version 18)
- Display of the original supplier in reverse charge self-invoices
  created by version 16
- Tax totals computation with version 16 logic
